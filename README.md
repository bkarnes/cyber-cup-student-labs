# Student Labs

A collection of lab exercises and solutions for the WV Cyber Cup 2026.

## Overview

This repository contains source code, scripts, and documentation for the various labs provided as part of the competition. Each lab is organized in its own subdirectory with a brief description and any required resources.

## Directory Structure

```
.
├─ lab1/          # Lab 1 description and code
├─ lab2/          # Lab 2 description and code
├─ ...
└─ README.md      # This file
```

## Getting Started

1. Clone the repository:
   ```bash
   git clone <repo-url>
   cd student-labs
   ```
2. Explore individual labs – each contains its own `README.md` with specific instructions.
